# MiniClaw 系统架构

## 当前状态

仓库已实现 Phase 0 的本地基础，仍未实现模型调用、飞书、工具或演进能力：

```mermaid
flowchart LR
    CLI["CLI: init / doctor"] --> PATHS["StatePaths"]
    CLI --> BOOTSTRAP["Bootstrap"]
    BOOTSTRAP --> CONFIG["Validated TOML Config"]
    BOOTSTRAP --> MIGRATION["SQLite Migration v1"]
    MIGRATION --> OWNER["Single Owner Repository"]
    CLI --> DOCTOR["Offline Doctor"]
    DOCTOR --> CONFIG
    DOCTOR -->|"read-only"| MIGRATION
```

`paths.py` 只派生绝对路径；`config.py` 只解析和校验；`storage/` 只管理 SQLite；
`bootstrap.py` 组合写入初始化；`doctor.py` 复用边界做只读检查，不执行修复。

## 一条消息的目标链路

```mermaid
sequenceDiagram
    autonumber
    actor User as 用户
    participant Channel as CLI / 飞书
    participant Agent as Agent Core
    participant Model as Model Provider
    participant Policy as Policy Engine
    participant Tool as Tool Registry
    participant Store as SQLite

    User->>Channel: 发送文本
    Channel->>Agent: 标准化 Message
    Agent->>Store: 加载会话与记忆
    Agent->>Model: Prompt + Tools
    alt 最终回答
        Model-->>Agent: Answer
    else 工具调用
        Model-->>Agent: Tool Call
        Agent->>Policy: 风险校验
        Policy->>Tool: 允许后执行
        Tool-->>Agent: Tool Result
        Agent->>Model: 继续推理
        Model-->>Agent: Answer
    end
    Agent->>Store: 保存消息和工具轨迹
    Agent-->>Channel: Reply
    Channel-->>User: 展示回答
```

## 包布局

Phase 0 已创建的文件标为“已实现”；其余目录只在对应阶段创建：

```text
src/miniclaw/
├── bootstrap.py # 已实现：幂等初始化
├── config.py    # 已实现：TOML 与环境变量配置
├── doctor.py    # 已实现：离线本地诊断
├── paths.py     # 已实现：状态路径边界
├── storage/     # 已实现：SQLite、migration、Owner
├── agent/       # 目标：模型与工具循环
├── channels/    # 目标：CLI、飞书与统一消息
├── evolution/   # 目标：反馈、评测、提案和回滚
├── policy/      # 目标：路径、命令、风险与审批
├── providers/   # 目标：OpenAI-compatible 模型边界
└── tools/       # 目标：文件、HTTP、受限 Shell
```

## 核心约束

- 单用户、单进程、一个 SQLite、一个 Workspace。
- Channel 只转换消息，Agent Core 不依赖飞书 SDK。
- 所有工具在执行前统一经过 Policy Engine。
- 文件路径解析后必须仍位于 Workspace，Shell 不接受拼接字符串。
- 自我改进只修改版本化 Prompt 或 Skill，并经过回放评测和人工批准。
- Telegram 与 Discord 复用 Channel 边界，但不进入 v0.1。
- `doctor` 使用 SQLite `mode=ro`，诊断缺失数据库时不得创建空文件。

详细数据模型、安全策略、部署图与演进流程见 [PRD](../product/20260807_产品需求文档.md)。
