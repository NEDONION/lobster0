# MiniClaw 本地运行指南

## 当前可以运行什么

仓库当前提供可安装的 `miniclaw` 包、帮助信息、版本命令和离线单元测试。Agent 对话、模型 Provider、
飞书 Gateway、SQLite 和工具将在后续里程碑实现。

## 环境要求

- Python 3.12 或更高版本。
- `uv`。
- macOS 或 Linux；当前脚手架不依赖 Docker 和外部服务。

## 安装

从仓库根目录执行：

```bash
uv venv
uv sync --extra dev
```

`uv` 默认在 `.venv/` 中创建环境。项目没有运行时第三方依赖，开发依赖当前只有 Ruff。

## CLI 验证

```bash
uv run miniclaw --version
uv run miniclaw
uv run python -m miniclaw --version
```

预期版本输出：

```text
miniclaw 0.1.0
```

无参数运行只显示帮助；`init`、`chat`、`doctor` 和 `gateway` 会在对应能力真正实现后加入，不提供虚假
占位命令。

## 开发检查

```bash
uv run python -m unittest discover -s tests -v
uv run ruff check .
```

这些检查不需要模型 Key、飞书凭证或网络。

## 配置说明

`.env.example` 只用于记录后续里程碑需要的配置名称。不要把真实密钥写入仓库；本地 `.env` 已由
`.gitignore` 排除。当前脚手架不会读取这些环境变量。
