## Known ceilings

- 当前版本没有运行真实 DeepSeek Memory/Skill/Compaction smoke；live LLM 仍是 release-only R3，而不是确定性 gate。
- `MEMORY.md` 由 Owner 手工维护；Agent 只能经审批追加 daily memory，尚无自动长期记忆合并。
- Skills 只加载 Markdown 指令，不执行 Python/Shell，也没有插件市场或远端安装。
- Compaction 使用本地字符估算和当前 Provider 摘要，不是 tokenizer 精确计数；原始消息保留用于审计和回放。
- 没有向量检索、Embedding、RAG、自动修改 Prompt/Skill/源码或自动部署。
- P2.3B 本机 `lark-cli` 路径 smoke 仍是独立待办；飞书、Telegram、Discord Channel 尚未实现。
