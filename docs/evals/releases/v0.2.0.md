## Reproduction

```bash
uv run python -m unittest discover -s tests -v
uv run ruff check .
uv run miniclaw eval validate --root evals/scenarios
uv run miniclaw eval run --suite offline --root evals/scenarios
git diff --check
```

Live gate 需要 owner-only `.env` 中的真实模型 Key，不能在 CI 或公开日志中运行。执行时只保存本页的脱敏结果，不保存
请求 Header、Key、完整本机原始数据或 Provider reasoning。

## Known ceilings

- 默认 Workspace 不是 Git 仓库，因此 live command smoke 验证的是 exact argv、审批、执行和错误回传，不是 Git 状态内容。
- HTTP live fetch 没有加入本次真实模型 smoke，SSRF/pinned peer/redirect 使用确定性 fake transport 与 Policy 测试；真实
  网络不应成为每次发布安全断言的唯一依据。
- 当前仅 CLI Channel；飞书、Telegram 和 Discord 尚未进入 Phase 2。
- Memory、Skills 与受控自我迭代属于下一阶段。
