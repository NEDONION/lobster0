> 记录日期：2026-08-09

> 结论：**IMPLEMENTATION PASS / DOCKER LIVE VERIFIED / SEATBELT LIVE PENDING**

v0.7.0 把 MiniClaw 从“收到消息后执行”推进到“可以按确定性计划长期运行”。它新增 durable Task Ledger、
one-shot/interval/cron Scheduler、Heartbeat、独立 TaskRun、预算、E-stop、主动 Channel Delivery、Approval
continuation、不可变 ExecutionPlan、Docker/Seatbelt backend、Checkpoint CAS 和冲突感知 Rollback。

这不是无限自治：Automation 和 Heartbeat 默认关闭；危险 Tool 仍要人工审批；模型不能创建递归 Task、扩大预算、
绕过 Policy 或自动批准；成功必须通过 `complete_task` terminal Tool 明确声明。

## 5. 已知限制

- Heartbeat 当前使用 `route=none`，可以执行和审计，但还不能主动通知 Owner；
- Checkpoint 只覆盖主 Workspace，不覆盖 Personal Profile 的外部 write roots；
- Rollback 暂无 Owner CLI/TUI；
- interrupted Run 不自动重放可能已经发生的副作用；
- 没有 Web 管理后台、分布式 Scheduler 或远程 Worker；
- Browser Agent 属于 **Phase 6.5 PLANNED / NOT IMPLEMENTED**。
