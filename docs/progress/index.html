安装与发布链路

面向普通用户的主安装方式是一行命令 curl -fsSL --proto '=https' --tlsv1.2 https://github.com/NEDONION/lobster0/releases/latest/download/install.sh | bash；Python 分发名是 lobster0-agent，CLI、import 与状态根保持 lobster0。

  • POSIX bootstrap → stdlib-only installer zipapp → 已校验 manifest → 版本化 Runtime staging
  • 受管 Python 3.12 / Node 24.18.0 / pi-tui bundle；用户无需预装 Python、Node.js 或 pnpm
  • smoke + 数据库保护 + 服务健康检查通过后才原子切换 current；保留 N-1 Runtime
  • 默认卸载保留全部用户数据；--purge-data 是唯一破坏性路径且始终保留 Workspace
  • 真机安装矩阵：本仓库自托管 runner 注册数实测为 0，从未运行
  • 包发布、镜像摘要冒烟与 attestation 校验：仓库当前没有任何 Release 或 tag，一行安装 URL 会 404
  • 升级入口：lobster0 update 按设计 fail closed（update_requires_bootstrap），升级方式是重新运行一行安装命令
