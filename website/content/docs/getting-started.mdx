## 一条命令装好

只需要 [`uv`](https://docs.astral.sh/uv/)。安装器会拉取发布 wheel 并把 `lobster0` 装成一个独立的
命令行工具，不污染你现有的 Python 环境。

<InstallCommand />

> **文件名必须保持原样。** `uv` 从 wheel 的文件名里读版本号，改名会直接报 `Must have a version`。
> `${W}` 外面的花括号也是必要的：在 macOS 默认的 zsh 里，裸写 `$W[feishu]` 会被当成数组下标。

中国大陆的机器建议加 GitHub 镜像和国内 PyPI 源，否则下载会很慢甚至中断：

## 配置并启动

```bash
lobster0 --version     # 应输出上面安装的版本号
lobster0 setup         # 交互式填写模型 API Key、飞书 App ID/Secret、Owner
lobster0 gateway       # 启动飞书网关（WebSocket 长连接，不需要公网端口）
```

`lobster0 setup` 是交互式的，所以它和上面的安装命令要分两次执行，不要一起粘贴。

密钥填错或需要轮换时，用 `lobster0 secret set LOBSTER0_MODEL_API_KEY` 就地改掉单个值；
`lobster0 secret list` 只列出已配置的变量名，不显示值。

> **不要 `rm -rf ~/.lobster0`。** 那会把记忆、会话历史、定时任务和审计记录一起删掉。

## 版本状态

<code>v<ReleaseVersion /></code> 是**预发布**。它已经在纯净的 Ubuntu 24.04 实机上验证到 `doctor` 全绿，可以用来自己部署，
但 Tier 1 真机矩阵、PyPI 发布与镜像 attestation 都还没跑，不应当作完整验证过的稳定版。

`install.sh` 形式的一行安装尚未产出（发布流水线的 `assemble` 阶段还没跑通），所以目前请用上面的
wheel 安装方式。

## 从源码运行

想改代码或跑测试才需要这条路径。除了 `uv`，还需要 Node.js `22.22.3 <= v < 23` 或
`24.15.0 <= v < 25`，以及 `pnpm`——因为要自己构建 TUI。

```bash
git clone https://github.com/NEDONION/lobster0.git
cd lobster0
uv sync --extra dev --extra channels
pnpm --dir tui install
pnpm --dir tui build
cp .env.example .env
uv run lobster0 init
uv run lobster0 doctor
uv run lobster0
```

`cp .env.example .env` 只创建本地配置文件。按模板填写 Provider 和可选 Channel 配置；不要把真实
API Key、App Secret 或 Token 提交到 Git。

没有合规 Node.js 时，可以临时用 Textual fallback：`LOBSTER0_TUI=textual uv run lobster0`。

> **建议先从 TUI 开始**
>
> 先在本地完成一次普通对话和一次需要审批的 Tool 调用，再接入消息平台。这样最容易判断问题来自
> Agent Core、Provider 还是某个 Channel Transport。

继续阅读[运行时](/docs/runtime)和[安全边界](/docs/security)。开发、测试与发布命令以仓库
[README](https://github.com/NEDONION/lobster0#readme) 和 `pyproject.toml` 为准。
