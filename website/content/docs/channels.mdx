## 四个入口

- **TUI：**本地主界面，适合初次配置、审批与排障。
- **飞书：**工作场景入口，拥有独立 Transport 与 Delivery 边界。
- **Telegram：**移动消息入口，队列和运行状态独立。
- **Discord：**社区消息入口，平台故障不会共享给其他 Channel。

## 配置顺序

1. 先按[安装与启动](/docs/getting-started)让 TUI 与 Provider 正常工作。
2. 在本地 `.env` 中填写目标平台需要的凭据，绝不提交真实 Secret。
3. 运行 Doctor 和对应的离线 Channel gate。
4. 再进行目标平台的真实回调、消息接收与发送验证。
