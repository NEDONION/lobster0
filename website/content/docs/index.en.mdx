MiniClaw is a small, complete, self-hosted personal AI agent with explicit boundaries. It puts Agent,
Policy, Approval, Tools, Memory, and multiple messaging surfaces around one Python core so capability
and control remain part of the same system.

## Pick a path

- **First run:** use [Install and run](/en/docs/getting-started) for dependencies, initialization, Doctor, and TUI startup.
- **Understand execution:** read [Runtime](/en/docs/runtime) to see how messages enter one AgentRuntime.
- **Set permissions:** read [Security boundaries](/en/docs/security) before choosing a Permission Mode.
- **Connect a platform:** read [Surfaces](/en/docs/channels) before the platform-specific repository guides.
- **Govern memory:** read [Memory](/en/docs/memory) for Markdown Truth and SQLite Projection.

## Current, verifiable scope

MiniClaw currently exposes four surfaces—TUI, Feishu, Telegram, and Discord—with 18 built-in tools,
33 versioned Channel cases, and 15 versioned Automation cases. Automation is disabled by default.

> **Evidence boundary**
>
> Passing local fake-SDK scenarios and soak runs is an Implementation PASS. It is not automatically a
> real-platform Live PASS; consult current release evidence for each real-platform Live Gate.
